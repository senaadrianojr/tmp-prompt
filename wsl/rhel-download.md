# Download do Red Hat Enterprise Linux para WSL

Página oficial de downloads da Red Hat:

https://developers.redhat.com/products/rhel/download

Para uso no WSL 2, procurar uma imagem específica para WSL (arquitetura `x86_64`). As opções **Boot ISO** e **DVD ISO** são para instalações convencionais, não para importação direta no WSL.

Se precisar exatamente do **RHEL 9.4**, confirmar a disponibilidade dessa versão para WSL antes de baixar, pois a página pode apresentar versões mais recentes.
